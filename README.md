# TS_HW3_makhmudov

Исследовательский проект по временным рядам.

## Проект по исследовательской теме 6
В работе проверяется, как способ кодирования сезонности влияет на качество прогноза на seasonal monthly-рядах из датасета M4.  
Сравниваются классические бейзлайны и одна глобальная ML-модель (`CatBoost`, `direct MIMO`) с разными наборами сезонных признаков.  
Подробная логика эксперимента, методология и интерпретация результатов описаны в отчете.

## Что внутри
- `project.ipynb` — основной ноутбук с экспериментом
- `test_of_functions.ipynb` — ноутбук для проверки функций
- `data_utils.py`, `split_utils.py`, `baseline_utils.py`, `metrics_utils.py` — работа с данными, сплитами, бейзлайнами и метриками
- `feature_configs.py`, `feature_utils.py`, `window_utils.py`, `model_utils.py`, `viz_utils.py` — ML-часть и визуализации
- `requirements.txt` — зависимости

## Основные выводы
- Сезонность лучше моделируется через явное добавление сезонных признаков, а не только через обычные лаги
- На фиксированной постановке лучший результат могли давать комбинации признаков, но в среднем наиболее универсальной оказалась спецификация с сезонными лагами
- Наиболее сильный эффект давало увеличение длины входной истории
- Влияние `model_horizon` незначительно, и заметнее проявлялось в моделях с Fourier-признаками
- Бейзлайны `AutoETS` и `AutoTheta` обыграть не удалось
